# Verificador de Idade
 
A simple age checker built as an HTML/CSS/JS practice exercise from CursoemVideo. Enter a birth year and gender, and it shows the calculated age along with a matching illustrative photo.
 
## Features
 
- Age calculation from birth year
- Gender selection (male/female)
- Displays a photo matching the age group (baby, child, young adult, adult, elderly) and gender
- Basic input validation
## Tech stack
 
- HTML5
- CSS3
- JavaScript (DOM manipulation)
## How to run
 
Just open `index.html` in your browser — no build step required.
